What You Get

01

Structured Handoffs

Every phase has a fitness gate. No half-deliverables pass downstream. The Delivery Lead verifies each transition.

02

Issue Triage

Bugs get routed by root cause, not symptom. A comprehensive taxonomy maps every issue type to the right owner.

03

Living Documentation

A product-level living spec aggregates shipped features. Tech debt is tracked in a register. Nothing hides.

04

Quality Gates

Each agent has a quality bar. The Tester and DevOps jointly own the release gate. No shortcuts to production.

05

Capability Audits

Before implementation starts, the Talent Manager checks if the team has the skills the spec demands.

06

Continuous Learning

User feedback and recurring issues become permanent team improvements — persona edits, skill docs, convention updates.

Get Started

1

Install from GitHub

Open Kiro → Powers panel → "Add power from GitHub" → paste:

https://github.com/nickharre/totara

Kiro will find the power-totara/ folder automatically.

2

Or install locally

Clone the repo, then point Kiro at the Power folder inside it:

git clone https://github.com/nickharre/totara.git

Then: Kiro → Powers → "Add power from Local Path" → select the totara/power-totara/ folder.

3

Start building

Mention keywords like "requirements," "design," or "triage" and Totara activates. Or invoke agents directly with @Marty, @Dieter, @Margaret, etc.
